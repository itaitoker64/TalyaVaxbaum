# Five-screen design review

This review follows the supplied references: warm Pilates and sage mobility interfaces for daily use, editorial composition for covers, and restrained bright-green actions. These are working app captures at a 390px mobile viewport, using explicitly labeled demo data. Missing photos now use restrained category typography labeled “צילום יתווסף בהמשך”; uploaded photos retain priority. No reference photographs have been republished as product imagery.

1. [Today](screenshots/review/1-today.png): prominent workout cover, one start action, week strip, complementary practices and compact goal summaries.
2. [Guided library](screenshots/review/2-library.png): consistent image-led cards, duration, level, equipment and visible video availability.
3. [Active workout](screenshots/review/3-active-workout.png): solid cream input surfaces, prescribed values, large set controls and a contrasting rest timer.
4. [Goal progress](screenshots/review/4-goal-progress.png): measured values, dates, baseline and target use distinct visual styles; no projections.
5. [Workout share card](screenshots/review/5-share-card.png): 1080×1920 export, selected recorded statistics, small brand mark, handle and demo label. Sharing remains user-initiated.

Interface headings and body text now use Heebo; Frank Ruhl Libre is reserved for brand and editorial moments. The photographic direction can be evaluated fully after Talya supplies her own assets; category uploads already replace placeholders. Updated after user feedback requesting a less AI-looking appearance: flatter surfaces, fewer nested cards, quieter navigation and a flat sand share-card background.
